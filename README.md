# CodeAlpha-Task1-LandingGear

# Landing Gear Assembly & Motion Study | SOLIDWORKS 2025

## 📌 Project Overview
This repository contains the complete 3D CAD design, assembly, and kinematic motion simulation of an aircraft **Landing Gear Assembly**, completed as part of **Task 1 for the CodeAlpha CAD/Mechanical Engineering Internship**.

The objective of this project was to model individual components with precise engineering constraints, assemble them using proper mechanical mates, and perform a Motion Study to simulate smooth extension and retraction mechanisms.

---

## 🛠️ Software & Tools Used
* **CAD Modeling & Assembly:** SOLIDWORKS 2025
* **Motion Simulation:** SOLIDWORKS Motion Study (Linear Motor setup)
* **Video Export Resolution:** 1080p (30 FPS)
